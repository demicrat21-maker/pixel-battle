# Пиксель-батл

Общий холст 128×96: игроки заходят по ссылке и ставят пиксели в реальном времени.
Сайт статический (работает на GitHub Pages), а данные хранятся в бесплатной базе Firebase.

- `index.html` — сама игра
- `admin.html` — админ-панель (доступна только тебе)
- `js/config.js` — сюда вставляется конфиг Firebase
- `database.rules.json` — правила безопасности базы (кулдаун, баны, права админа)

## Что умеет админка

- статистика: онлайн, количество пикселей, баны
- осмотр любого пикселя: кто поставил (ник и ID), когда
- бан игрока, стирание одного пикселя или всех пикселей игрока
- стирание прямоугольной области
- рисование без кулдауна
- изменение кулдауна, объявление для всех игроков, закрытие/открытие холста
- скачать поле картинкой PNG, полная очистка поля

Кулдаун и баны проверяет сервер Firebase, а не браузер, поэтому обойти их через код страницы нельзя.

## Установка (≈15 минут)

### 1. Firebase

1. Зайди на https://console.firebase.google.com → **Add project** (Google Analytics можно выключить).
2. Слева **Build → Realtime Database → Create database**. Регион — `europe-west1` (Бельгия), режим — **locked mode**.
3. **Build → Authentication → Get started → Sign-in method** и включи два способа:
   - **Anonymous** (так входят игроки, ничего не вводя);
   - **Google** (так входишь ты в админку).
4. **Project settings** (шестерёнка) → внизу **Your apps** → значок `</>` (Web) → любое имя → **Register app**.
   Скопируй объект `firebaseConfig` и вставь его значения в `js/config.js` вместо `ВСТАВЬ_СЮДА`.
   Обрати внимание на `databaseURL` — он должен быть как в консоли.
5. **Realtime Database → Rules** → удали всё, вставь содержимое `database.rules.json` → **Publish**.

### 2. GitHub Pages

1. Создай новый публичный репозиторий на GitHub, например `pixel-battle`.
2. **Add file → Upload files** → перетащи ВСЕ файлы и папки из этого архива (включая `css`, `js`, `.nojekyll`) → **Commit**.
3. **Settings → Pages** → Source: **Deploy from a branch**, ветка `main`, папка `/ (root)` → **Save**.
4. Через минуту-две сайт будет по адресу `https://ТВОЙ_НИК.github.io/pixel-battle/`.
5. Вернись в Firebase: **Authentication → Settings → Authorized domains → Add domain** → `ТВОЙ_НИК.github.io`.
   Без этого не будет работать вход через Google в админку.

### 3. Сделать себя админом

1. Открой `https://ТВОЙ_НИК.github.io/pixel-battle/admin.html` и войди через Google.
2. Появится «Нет доступа» и твой ID — нажми «Скопировать мой ID».
3. Firebase → **Realtime Database → Data** → наведи на корень → **+**:
   - Key: `admins`, затем внутри него **+** → Key: *твой ID*, Value: `true` (тип boolean).
4. Обнови страницу админки — панель откроется.

Админом станет только тот, чей ID ты сам добавил в базу. Ссылку `admin.html` можно знать кому угодно — без записи в `admins` она ничего не даст.

Ссылку на игру (`https://ТВОЙ_НИК.github.io/pixel-battle/`) просто кидаешь людям.

## Настройка

- Размер поля — `W` и `H` в `js/config.js` (максимум 200×100, иначе нужно менять регулярку в правилах).
- Палитра — `PALETTE` в `js/config.js` (ровно 16 цветов, иначе поправь `<= 15` в правилах).
- Кулдаун меняется прямо в админке.

## Ограничения

- Игроки анонимные: если человек очистит данные браузера или зайдёт в режиме инкогнито, он получит новый ID
  (и выйдет из бана). Для небольшой игры с друзьями это нормально. Если начнут злоупотреблять — можно включить
  **Firebase App Check** или перейти на вход через Google для игроков.
- Бесплатный тариф Firebase (Spark): до 100 одновременных подключений и 10 ГБ трафика в месяц.
  Для батла на несколько десятков человек этого хватает с запасом.
